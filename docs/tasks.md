\# Git DevOps Workflow Project



\## 1. Project Objective



The objective of this project is to practice Git and GitHub workflows used in DevOps environments, including version control, branching, commits, and collaboration.



\## 2. Tools Used



\- Git

\- GitHub

\- Git Bash

\- Markdown



\## 3. Tasks Completed



\### Task 1: Initialize the Repository

\- Created the project directory.

\- Initialized a Git repository.

\- Created the initial README file.

\- Committed the initial project files.



\### Task 2: Create and Manage Branches

\- Created the `main` branch.

\- Created the `dev` branch for development work.

\- Created the `feature/project-setup` branch for project setup tasks.

\- Practiced branch management and naming conventions.



\### Task 3: Organize Project Files

\- Created the `.gitignore` file.

\- Created the `docs` directory.

\- Created this task documentation file.

\- Added ignore rules for environment files, logs, editor settings, and temporary files.



\## 4. Planned Tasks



\- Create and configure a GitHub repository.

\- Connect the local repository to GitHub.

\- Push the project branches to the remote repository.

\- Practice Pull Requests to merge feature work into `dev`, then `dev` into `main`.

\- Create a version tag such as `v1.0.0`.

\- Verify the final repository structure and Git history.



\## 5. Expected Outcome



A well-organized, version-controlled DevOps project demonstrating Git fundamentals, branching strategies, documentation, and a basic collaborative workflow.
